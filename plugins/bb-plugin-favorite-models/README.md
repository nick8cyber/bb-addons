# bb-plugin-favorite-models ⭐

Плагин для **BB (Big-AGI / bb-app)**, позволяющий добавлять модели провайдеров в избранное с помощью звёздочки (⭐) и автоматически закреплять их поверх общего списка моделей для быстрого выбора.

Особенно полезно, когда у провайдеров (OpenRouter, LiteLLM, Ollama, CLIProxyAPI, Codex, Pi, Antigravity/AGY, Claude Code и др.) подключены десятки или сотни моделей.

---

## 🚀 Возможности

1. **⭐ Звёздочки у моделей в выпадающем списке**:
   - В меню выбора модели у каждой строки появляется иконка звёздочки (⭐ / ☆).
   - Один клик на звёздочку добавляет или убирает модель из избранного без случайного выбора самой модели и без закрытия меню.
2. **📌 Закрепление избранного вверху списка (`Pin to Top`)**:
   - Избранные модели автоматически поднимаются на самый верх списка моделей в отдельный блок **⭐ Избранные модели**.
   - Поиск по моделям (`Search models`) сохраняет приоритет избранных моделей в результатах.
3. **⚡ Быстрый переключатель в поле ввода (Composer Action)**:
   - В панели действий поля ввода добавляется кнопка **⭐ Избранное** с бейджем количества моделей.
   - Позволяет в один клик переключиться на нужную избранную модель текущего или других провайдеров.
4. **⚙️ Настройки и управление в интерфейсе BB (`Settings → Избранные модели`)**:
   - Просмотр всех сохранённых моделей с группировкой по провайдерам.
   - Ручное добавление любой модели и удаление ненужных.
   - Экспорт и импорт списка избранных моделей в формате JSON.
   - Включение/отключение закрепления вверху списка и кнопки в панели ввода.
5. **💻 CLI-команда `bb favorites`**:
   - Управление избранным прямо из терминала:
     - `bb favorites` или `bb favorites list` — список всех избранных моделей.
     - `bb favorites add <provider> <model>` — добавить модель в избранное.
     - `bb favorites remove <provider> <model>` — удалить модель из избранного.
     - `bb favorites clear [provider]` — очистить избранное.
     - `bb favorites export` — вывести JSON со всеми избранными моделями.

## 📦 Установка

```bash
# Из локальной директории:
bb plugin install /home/ubuntu/dev/bb-plugin-favorite-models
```

## 🛠️ Сборка и разработка

```bash
cd /home/ubuntu/dev/bb-plugin-favorite-models

# Проверка типов TypeScript:
npm run typecheck # или npx tsc --noEmit

# Сборка плагина (backend + frontend):
bb plugin build

# Перезагрузка плагина в работающем BB:
bb plugin reload favorite-models
```

## 📂 Структура проекта

| Файл / Папка | Назначение |
| --- | --- |
| `server.ts` | Бэкенд-сервер плагина: RPC-методы, KV-хранилище, CLI-команда `bb favorites` |
| `app.tsx` | Фронтенд плагина: регистрация контент-скрипта, настроек и кнопки в композере |
| `src/dom-observer.ts` | MutationObserver: поиск меню выбора моделей, внедрение звёздочек, подъём избранного наверх |
| `src/favorites-manager.ts` | Управление состоянием избранного (localStorage + backend RPC sync + event bus) |
| `src/QuickFavoritesAction.tsx` | Быстрое выпадающее меню со списком избранного в панели ввода |
| `src/SettingsSection.tsx` | Интерфейс настроек: список избранного, ручное добавление, экспорт/импорт JSON |
| `src/icons.tsx` | SVG-иконки звёздочек (Filled / Outline) и вспомогательных элементов |
| `icons/star.svg` | Иконка плагина для настроек и каталога расширений BB |
