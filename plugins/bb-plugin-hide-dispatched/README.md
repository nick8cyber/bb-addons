# bb-plugin-hide-dispatched

Плагин для **BB**, который автоматически прячет из сайдбара треды, порождённые
раздачей задач (`bb tasks dispatch`), переводя их в `visibility: "hidden"`.

## Зачем

`bb tasks dispatch` спавнит тред без родителя и с обычной видимостью, поэтому
раздача засоряет корень сайдбара. Встроенной настройки для этого нет. Скрытый
тред остаётся живым и полностью отслеживается панелью Tasks — её статусы идут
через события `thread.*` и `threads.get` по прямому ID.

## Поведение

- На событие `thread.created` плагин проверяет `thread.originPluginId`. Если он
  входит в список отслеживаемых (по умолчанию `["tasks"]`), тред сразу переводится
  в `visibility: "hidden"`.
- Если тред уже скрыт — ничего не пишется.
- Треды с другим `originPluginId` и треды без него (обычные пользовательские) не
  трогаются ни при каких условиях.
- Плагин ничего не удаляет, не архивирует и не останавливает. Единственная
  операция записи — переключение `visibility`.
- Ошибки `threads.update` перехватываются и логируются, не роняя создание тредов.

## CLI-команда `bb hide-dispatched`

```
bb hide-dispatched status              # включён ли плагин, какие originPluginId
                                       # отслеживаются, сколько тредов скрыто
bb hide-dispatched on                  # включить скрытие
bb hide-dispatched off                 # выключить скрытие
bb hide-dispatched sweep               # разовая уборка существующих видимых тредов
bb hide-dispatched sweep --dry-run     # только показать кандидатов, ничего не менять
```

Все подкоманды поддерживают `--json` для машиночитаемого вывода.

Состояние (включён/выключен, список отслеживаемых, счётчик скрытых) хранится в
`bb.storage.kv` и переживает перезапуск. По умолчанию скрытие включено.

## Установка

```bash
bb plugin install /path/to/plugins/bb-plugin-hide-dispatched
```

## Сборка и проверка

```bash
npm install
npm run typecheck   # tsc --noEmit, без ошибок
```
