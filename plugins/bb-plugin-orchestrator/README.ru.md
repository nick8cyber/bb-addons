# bb-plugin-orchestrator

Раздача задач `bb tasks` на треды исполнителей по политике (спека:
`docs/specs/orchestrator.md`, ADR-0015). Полное описание —
[README.md](README.md) (английский).

## Язык (`language`, §18.1)

Настройка `language`: `en` | `ru`, по умолчанию `en`. Определяет язык
всех текстов, которые плагин порождает для людей и агентов: строки
координатору, ответы CLI и инструментов, инструкции исполнителю
(«задача без кода», «Заход N», напоминание о вердикте), правило
координатора, тексты ролей, памятка git по умолчанию, сообщения
git-хука `pre-push`.

- Строки лежат в каталогах `src/i18n/<язык>.ts` по ключам. Ключа нет в
  выбранном языке — берётся английское значение и пишется предупреждение
  в журнал.
- Не переводятся (машинные контракты): JSON вердикта, коды ошибок,
  имена полей и настроек, маркеры `prBody`, метки журналов.
- Подписи настроек в схеме BB — английские.

### Памятка git

Значение `gitInstructions`, совпадающее со встроенным текстом любого
языка, считается значением по умолчанию и выводится на текущем языке;
изменённое владельцем — как есть, пустая строка выключает раздел (§2.2).

### Навыки

Два набора: английский `orchestrator-coordinator` / `orchestrator-setup`
и русский `orchestrator-coordinator-ru` / `orchestrator-setup-ru`. Плагин
объявляет (`configure`) только набор текущего языка.

### Git-хук `pre-push`

Тексты хука версионированы вместе с языком: установленный хук сравнивается
с отрисовкой текущего языка, и смена `language` переустанавливает его
(иначе `release` откажет `hook-stale`). Источник `hooks/pre-push` —
русский вариант; блок `MESSAGES` переписывается под выбранный язык.
