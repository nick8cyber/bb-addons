# Thread Timestamps

Дата и время каждого сообщения пользователя и агента постоянно видны в треде BB: `13.10.2026 20:11`. Используется время сообщения из BB и часовой пояс браузера. Работает с новыми сообщениями, историей и несколькими открытыми панелями.

## Происхождение

Форк [Message Timestamps от bighitbiker3](https://github.com/bighitbiker3/bb-plugin-message-timestamps) на основе commit `fc365a7dde2cc12eef9fdc952c810b9798df8784`. Сохранена схема upstream: RPC читает timeline, content script добавляет подписи через DOM-атрибуты и CSS. Реализация расширена на обе роли, использует стабильные атрибуты строк и ограниченный кеш с продолжением пагинации.

У форка свой ID `thread-timestamps`; upstream `message-timestamps` после проверки замены удаляется.

## Проверка и установка

```bash
npm install
npm run typecheck
npm test
bb plugin build
bb plugin install path:. --yes
```

Контракт: [спецификация](../../docs/specs/thread-timestamps.md).

## Результат проверки

Проверка типов, 14 поведенческих тестов и сборка проходят. В живом BB проверены сообщения обеих сторон, входящие сообщения других агентов, светлая и тёмная темы, экраны 1440 и 390 px. Подписи видны без hover при отключённом upstream; старый плагин удалён, замена работает самостоятельно.

## Ограничения

Подписи добавляются только к сообщениям с timestamp в BB. Служебные строки и вызовы инструментов не получают подпись. Старые сообщения могут получить её после нескольких ограниченных запросов истории. Плагин использует content script, поскольку SDK не предоставляет слот дополнения стандартных сообщений; при смене DOM BB это проверяется браузерным тестом.
