Hide sensitive data in the bb interface with one click — for screenshots,
demos and screen sharing.

## What you get

- An eye button in the sidebar footer and the `Alt+Shift+P` shortcut that
  toggle privacy mode.
- Emails, bb ids, paths, URLs, domains, IPs, UUIDs, tokens, phone numbers,
  `@handles`, project and host names, and your own words are blurred in place.
- Inputs, the terminal and avatars are blurred as whole elements.

## How it works

Text is masked through the CSS Custom Highlight API, so the page DOM is never
rewritten. Project and host names come from this bb server; nothing leaves
the machine.
