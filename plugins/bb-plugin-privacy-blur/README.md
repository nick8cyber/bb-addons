# bb-plugin-privacy-blur

Один клик — и интерфейс bb готов к скриншоту или демонстрации экрана:
чувствительные данные размываются прямо на месте.

## Как включить

| Способ | Что делает |
|---|---|
| Кнопка-глаз в подвале сайдбара | Включает/выключает режим |
| `Alt+Shift+P` | То же с клавиатуры |
| Плашка «Данные скрыты» справа внизу | Видна, пока режим включён; клик — выключить |

Состояние хранится в `localStorage` браузера и синхронизируется между вкладками.
Удалённый зритель и локальное окно переключаются независимо.

## Что скрывается

- **Шаблоны:** почты, URL, абсолютные и `~/` пути, пути Windows, id bb
  (`thr_…`, `proj_…`, `env_…`, `mem_…`, `host_…`), UUID, длинный hex
  (SHA, хэши), ключи API (`sk-…`, `ghp_…`, `xox…`, `AKIA…`, JWT), IPv4/IPv6,
  домены, телефоны `+…`, `@логины`.
- **Слова с сервера** (`autoTerms`): названия проектов, имена хостов,
  hostname и пользователь ОС, `git config --global user.name/email`,
  хост публичного адреса bb. Слова короче 3 символов пропускаются.
- **Свои слова** (`customTerms`): имена людей, компании, клиенты.
- **Элементы целиком:** поля ввода (кроме того, где курсор), терминал,
  аватары; по желанию — заголовки тредов и любые CSS-селекторы.
- **По желанию (выключено по умолчанию):** заголовки тредов
  (`blurThreadTitles`) и имена людей — два слова подряд с заглавной (`detectNames`).
- **С адреса страницы и списка серверов:** имя инстанса (`sursun` из `sursun.getbb.app`).

## Настройки

```bash
bb plugin config privacy-blur set customTerms "Иван Петров, Acme, client-x"
bb plugin config privacy-blur set blurThreadTitles true
bb plugin reload privacy-blur
```

Слова перечитываются при каждом включении режима; настройки плагина — после reload.

## Ограничения

- Текст, разбитый на несколько DOM-узлов (подсветка синтаксиса по токенам),
  ловится только по частям.
- Слова с сервера кэшируются в браузере. При самом первом включении в новом
  браузере названия проектов скрываются после ответа сервера (доли секунды).
- Всплывающие `title`, адресная строка браузера и содержимое `<canvas>`
  не скрываются (терминал размывается целиком).
- Нужен браузер с CSS Custom Highlight API (Chrome 105+, Safari 17.2+,
  Firefox 140+). В остальных размывается весь элемент с совпадением.
