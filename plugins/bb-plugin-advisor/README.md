# Advisor

Независимый ревьюер BB: проверяет работу перед завершением ответа, хранит цепочки замечаний и проверяет завершённые треды. Ошибка самого ревью отображается как недоступная проверка, а не одобрение.

## Происхождение

Поддерживаемая MIT-копия [salemsayed/bb-plugin-advisor](https://github.com/salemsayed/bb-plugin-advisor), установленный snapshot `bd4b6aeba3bea0bc75472be7556dc2bb8845aed8`, версия 0.1.0, включая существовавшие локальные доработки. Исходный автор — Salem Sayed Abdel Gawad; исходный дизайн — [oh-my-pi](https://github.com/can1357/oh-my-pi). Уведомление об авторских правах сохранено в [LICENSE](LICENSE).

Идентификатор — `advisor`. При замене источника на эту копию сохраняются его БД, настройки и сессии. Cache/core BB не редактируются. Изменения хранятся в bb-addons; установленная path-копия не отслеживает обновления стороннего marketplace-пакета.

## Язык результатов

`outputLanguage=ru` по умолчанию. Каждый запрос требует русский текст `summary` и `details`, включая старые сессии. При английской или смешанной прозе выполняется один дополнительный запрос на перевод в той же сессии и той же моделью, максимум 30 секунд сверх бюджета ревью.

Перевод возвращает только два текстовых поля. Уровень замечания, ключ и закрытие замечаний берутся из исходного ревью. Код, команды в code-блоках, пути, URL, цитаты и числовые значения защищаются плейсхолдерами.

> [!WARNING]
> При неудаче перевода замечание остаётся видимым на исходном языке с предупреждением «Не удалось перевести ревью на русский; показан оригинал». Оценка сохраняется. Проверка языка эвристическая и не доказывает смысловую эквивалентность перевода.

`outputLanguage=auto` отключает языковую инструкцию и перевод. Старый переключатель `ru.advisorRussian` больше не управляет ревью. Исторические результаты автоматически не переписываются.

## Управление

| Команда | Назначение |
|---|---|
| `bb plugin config advisor` | Текущие настройки |
| `bb plugin config advisor set outputLanguage ru` | Русские новые результаты |
| `bb plugin config advisor set outputLanguage auto` | Язык без проверки |
| `bb advisor status [thread-id]` | Состояние ревью |
| `bb advisor reviews [thread-id]` | Сохранённые результаты |

Существующие настройки автоматического ревью/продолжения, порога важности, бюджета времени, моделей по машинам и инструмент `advisor_review` продолжают работать.

## Проверка и установка

~~~sh
npm ci
npm run typecheck
npm test
npm run build
~~~

Перед заменой источника сохранить БД и настройки, дождаться завершения активного ревью и согласовать замену с агентами проекта. Постоянный путь — `bb-addons/plugins/bb-plugin-advisor`. Откат возвращает прежний source; исторические записи БД не удаляются.
