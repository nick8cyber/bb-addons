# Server Switcher

A standard monochrome footer icon opens the current BB server and the complete account server list in one click. The panel starts closed and has no additional dropdown, avatars, or colored rings.

- Browser: choosing an online server opens its URL in the current tab.
- Desktop: switching uses the native BB server menu.
- Native mobile app: the server list is read-only.
- Offline servers are visible and disabled; online state remains visible beside each server icon.

Requires BB signed in to its account and the bundled Connect plugin. Authentication and account connections remain native. The original ring CLI and saved data stay compatible; the panel does not display rings.
