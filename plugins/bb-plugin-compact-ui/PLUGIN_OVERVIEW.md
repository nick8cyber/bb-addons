Компактный список чатов BB: в каждом проекте видны первые N обычных веток, остальные раскрываются порциями: 3 → 10 → 20 → 30 при исходном лимите 3. Кнопки «Ещё N» и «Меньше» расположены рядом со счётчиком «X из Y»; сворачивание тоже по одной порции.

## Возможности

- Закреплённые и активные чаты остаются видимыми; по настройке не скрываются ветки, требующие ответа или завершившиеся с ошибкой.
- «Непрочитанные сверху» поднимает ветки с непрочитанными чатами, сохраняя закреплённые первыми и дочерние чаты под родителем. По умолчанию выключено.
- Проекты можно сворачивать и переставлять; доступны переименование, закрепление, отметка прочтения, ссылка, открытие рядом и архивирование тредов.
- Окно ввода сообщения ограничено 1/3 рабочей области: вложения и кнопки остаются видимыми, лишняя высота уходит в скролл текста; на desktop и мобильном одинаково.
- Меню навигации сайдбара свёрнуто в строку иконок и поднято в верхний chrome-ряд рядом со стрелками «Назад/Вперёд» (клоны пробрасывают клики на настоящие кнопки, «Ещё» открывается): вертикальное меню не ест высоту списка чатов.

## Настройка

Открой настройки Compact UI. `visibleThreads` задаёт лимит; 0 показывает все чаты. `unreadFirst` включает сортировку по непрочитанным. `useCollapsedList` возвращает штатный список без удаления плагина.

Настройки хранятся в BB; отдельные аккаунты и внешние сервисы не нужны.
