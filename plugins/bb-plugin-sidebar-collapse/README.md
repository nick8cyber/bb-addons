# bb-plugin-sidebar-collapse

Плагин для bb, заменяющий прокручиваемый список тредов в левом сайдбаре своим списком со свёрткой чатов сверх лимита (поведение сайдбара Claude).

В каждом проекте отображаются первые N обычных корневых чатов (по умолчанию 5). «Ещё N» раскрывает до ближайшей десятки, затем по 10: при лимите 3 это 3 → 10 → 20 → 30. «Меньше» в той же строке убирает одну порцию, вплоть до исходного лимита. Счётчик «X из Y» показывает число корневых чатов без дочерних.

Последняя неполная порция: 20 → 27 → 20. Сократившийся список не требует холостых кликов. Бюджет каждого проекта независим, сохраняется при сворачивании заголовка и обновлении списка; перезагрузка страницы или смена visibleThreads возвращает исходный лимит.

## Возможности

- **Скрыть полосу навигации**: настройка hideNavigationRail скрывает узкую полосу Home/Tasks/More в развёрнутом списке чатов. При скрытом Rail внизу остаётся кнопка «Настройки Sidebar Collapse» со значком ChevronsUp. В Top list она не дублирует штатный Settings: настройки плагина открываются из Settings. В Settings/Plugins/Skills и при свёрнутом desktop-sidebar полоса штатная.
- **Постоянные действия строки**: «Скопировать ссылку → ⋯» видны без наведения на desktop и touch/PWA. Архивация находится только в меню, чтобы избежать случайных нажатий. Ошибка Clipboard не выдаётся за успешное копирование.
- **Файлы в верхнем баре**: вместо полосы `Untracked · N files` над полем ввода — кнопка в header чата; на телефоне и в узком pane она показывает иконку и число. Открывает родной список файлов под верхним баром. Escape и внешний клик закрывают список. Другие context segments сохраняются; без подходящей разметки BB остаётся родной интерфейс.
- **Очередь на телефоне**: штатные кнопки отправки, редактирования и удаления видны сразу в строке сообщения. Desktop, блокировки и обработчики BB сохраняются.
- **Контраст счётчика Top list**: нейтральная плашка использует цвета sidebar/sidebar-foreground; числа и warning/critical тона не меняются.
- Скрытие независимо от выбора списка чатов. Пагинация «Ещё N / X из Y / Меньше» сохраняется.

### Совместимость с BB 0.47

BB 0.47 вернул штатный выбор **Appearance → Navigation → Rail / Top list / плагин**. Top list сам убирает вертикальную колонку, но показывает навигацию над чатами — это не полное скрытие навигации. Наш плагин не меняет этот выбор: на Top list ничего не скрывает. Для стандартного Rail есть отдельная проверка новой grid-разметки; неизвестная структура остаётся штатной (fail-open).

Текущий сервер BB не обновляется при установке плагина. Подробности и границы проверки: [контракт совместной поставки](../../docs/specs/sidebar-rail-combined.md).

### Возврат полосы

При скрытом Rail открой «Настройки Sidebar Collapse» внизу и выключи «Скрыть полосу навигации». В Top list используй штатную шестерёнку Settings → Sidebar Collapse; дублирующая кнопка плагина там скрыта. Штатная команда **Open settings** и её клавиша из текущего BB тоже остаются доступны. При скрытой полосе desktop-sidebar можно свернуть, чтобы временно увидеть штатные пункты Home/Tasks/More. Отключение плагина очищает его стили. Плагин не является полной заменой навигации.

### Список чатов

Переключатель `useCollapsedList` выбирает наш или штатный список через публичную настройку BB `sidebar.threadListProvider`. Это работает и в новых BB, где компонент `Original` больше не передаётся плагинам. Выбор стороннего плагина списка не перезаписывается. Настройка скрытия полосы от этого выбора не зависит.

- **Свёртка чатов проекта**: ограничение числа одновременно видимых строк с кнопкой «Ещё N» / «Меньше».
- **Сворачивание проектов**: шеврон у названия проекта позволяет скрыть весь список тредов проекта.
- **Порядок проектов мышкой**: заголовок проекта перетаскивается; линия показывает, встанет проект выше или ниже цели. Фронтендового действия для этого в SDK нет, поэтому перемещение уходит в `server.ts` и выполняется через `bb.sdk.projects.reorder`.
- **Действия с тредами**:
  - Открытие треда обычным кликом с закрытием мобильного меню (`onNavigate`).
  - Открытие в сплите по `Cmd+клик` / `Ctrl+клик` (если сплит доступен).
  - Индикатор состояния (`waiting-for-input`, `unread-error`, фоновые агенты и др.).
  - Индикатор закрепления (`Pin`).
  - Отображение имени ветки git-окружения (`GitBranch`) — по галочке `showBranchName`.
  - Подсветка активного треда (`aria-current="page"`).
  - Инлайн-переименование по двойному клику на заголовок или через меню (Enter сохраняет, Esc или blur отменяют).
  - Быстрое действие `Archive` иконкой в строке (появляется по наведению или
    фокусу, на тач-экранах видно всегда).
  - Контекстное меню (правый клик) и меню кнопки действий (`MoreHorizontal`):
    - `Open in split`
    - `Pin` / `Unpin`
    - `Mark as read` / `Mark as unread`
    - `Rename`
    - `Archive`
    - `Delete` (destructive)
- **Клавиатурные шорткаты**: соблюдение DOM-контракта bb (`a[data-sidebar-thread-shortcut-target][data-sidebar-thread-id]`, `tabIndex={0}`, `button[aria-expanded]`).
- **Корректная деградация**: при ошибке загрузки данных плагин плавно отображает родной список хоста (`<Original />`).

## Что лимит считает, а что нет

`visibleThreads` ограничивает только **обычные корневые** чаты проекта.
Никогда не скрываются под «Ещё N»:

- закреплённые чаты (`Pin`) — закрепление и есть способ сказать «держи на виду»;
- активный чат и вся цепочка его родителей;
- чаты, которые ждут ответа или упали с ошибкой, — пока включён `keepAttention`.

Поэтому при пяти закреплённых чатах и `visibleThreads = 5` в проекте видно
пять закреплённых плюс пять обычных, а `Ещё N` показывает, сколько
обычных чатов откроется следующим нажатием. Дочерние (форкнутые) треды рисуются с отступом под
своим родителем и в лимит не входят; если родитель скрыт, скрыты и они.

## Чего плагин не умеет по сравнению с родным списком bb

Слот `experimental_threadList` — эксклюзивный: плагин рисует весь
прокручиваемый список целиком, поэтому всё, что здесь не реализовано,
в сайдбаре пропадает:

- виртуализация длинных списков (рисуются все строки в выбранном количестве порций);
- группировка по секциям проекта (`sectionId`) — треды секции попадают
  в общую группу своего проекта;
- бейджи pull request (`experimental_useSidebarThreadPullRequest`);
- миникарта размещения сплитов (`layout.panes`);
- перетаскивание тредов между проектами и переупорядочивание закреплённых
  (порядок самих проектов мышкой работает, см. ниже).

Вернуть родной список bb можно без удаления плагина — двумя способами:
`bb plugin config sidebar-collapse set useCollapsedList false` или
**Settings → Appearance → Sidebar**, где выбирается, чей список рисовать.

## Настройки

### Непрочитанные сверху

Включи **Непрочитанные сверху** (`unreadFirst`) в настройках Sidebar Collapse, чтобы внутри каждого проекта сначала видеть закреплённые чаты, затем ветки с непрочитанным корнем или дочерним чатом, затем остальные. Внутри этих категорий сохраняется сортировка по активности; дочерние чаты остаются под родителем в порядке создания. Архивные чаты не учитываются.

По умолчанию опция выключена, поэтому существующий порядок не меняется. Лимит, «Показать ещё», сворачивание проектов и видимость активного чата продолжают работать. Настройка сохраняется на сервере и применяется к открытым спискам без перезагрузки страницы.

Включить через CLI: `bb plugin config sidebar-collapse set unreadFirst true`. Вернуть прежний порядок: `bb plugin config sidebar-collapse set unreadFirst false`.

### Остальные параметры

Настройки объявляются в `server.ts` и редактируются через настройки bb или CLI:

- `useCollapsedList` (`boolean`, по умолчанию `true`): выключи, чтобы вернуть
  родной список тредов bb, не удаляя плагин.
- `visibleThreads` (`number`, по умолчанию `5`): сколько чатов проекта видно до нажатия «Ещё N». Значение `0` показывает все треды без свёртки.
- `keepAttention` (`boolean`, по умолчанию `true`): не скрывать под «Ещё N» чаты, которые ждут ответа или завершились с ошибкой.
- `showBranchName` (`boolean`, по умолчанию `false`): дописывать в строку чата
  имя ветки его окружения. Родной список bb ветку не показывает, поэтому
  галочка выключена.
- `showThreadCount` (`boolean`, по умолчанию `false`): дописывать в заголовок
  проекта число его корневых чатов.

Настройка через CLI:

```bash
bb plugin config sidebar-collapse
bb plugin config sidebar-collapse set visibleThreads 10
bb plugin config sidebar-collapse set useCollapsedList false   # вернуть список bb
bb plugin reload sidebar-collapse
```

## Структура файлов

- `app.tsx` — фронтенд плагина, регистрирует слот `slots.experimental_threadList` (`id: "collapsed"`).
- `server.ts` — бэкенд плагина, объявляет настройки `visibleThreads` и `keepAttention`.
- `lib/thread-groups.ts` — модуль группировки тредов по проектам и вычисления видимых строк.
- `app.test.tsx` — набор тестов поведения списка на `@get-bb/plugin-sdk/testing/app`.
