# e2e — живые проверки звонка в настоящем Chromium

Headless Chromium (Playwright) открывает BB, подменяет микрофон синтезированной фразой и звонит кнопкой телефона в футере сайдбара. Проверка — снаружи, по `bb call transcript <callId>` и логу плагина. Ключ AI Studio для синтеза — `K=<ключ>`, путь к браузеру — `EXE=<chrome-headless-shell>`. Результаты пишутся в `./out/`.

| Скрипт | Что проверяет |
|---|---|
| `shot.mjs` | скриншот BB (`URL`, `W`, `H`, `EVAL`) |
| `speech-e2e.mjs` | фраза `P` голосом → транскрипт, карточки, переход «Открыть», итог |
| `c-e2e.mjs` | несколько фраз через паузу (`P="a|b|c"`, `GAP`): подтверждение запуска «да» → подсказка, «отмена» → отмена |
| `x-e2e.mjs` | то же в Extended (`EXT=1`, `DELAY`) |
| `d-e2e.mjs` | старт в Extended и переключение на «Быстрый» |
| `m-e2e.mjs` | телефонная ширина (`W=390 H=844`) |
| `r-e2e.mjs` | обрыв WebSocket посреди звонка → возврат в тот же звонок |
| `reload-e2e.mjs` | закрыть страницу и открыть новую → тот же звонок |
| `rl-e2e.mjs` | `bb plugin reload` посреди звонка → новый звонок без падения (не запускать, пока звонит владелец) |
| `ext-prompt-ab.mjs` | A/B двух системных инструкций Extended на «системную ошибку» |
| `voicecmp.mjs` | высота голоса у разных моделей и голосов |
| `keycheck.mjs` | живы ли ключи плагина (`F=<файл ключей>`) |

Перед любым `bb plugin reload` — `bb call status`: перезагрузка рвёт идущий звонок.
