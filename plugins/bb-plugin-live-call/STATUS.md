# Live Call — статус и передача работы

> [!IMPORTANT]
> Кода плагина нет. Готовы исследование, архитектура, решения владельца, макеты и спайк. Следующий шаг — спайки Ф0, затем задачи в `bb tasks` по процессу владельца.

## Сделано

- [x] Исследование Gemini Live API: модели, задержки, ограничения сессии, перебивание, возобновление — [спека §1](../../docs/specs/live-call.md).
- [x] Нативные вызовы инструментов у `gemini-3.8-live-extended-thinking` не работают на стороне Google: 0 из 21 сессии (свой клиент, официальный SDK, голосовой ввод). У `gemini-3.8-live` работают за ~1 с.
- [x] Рабочий режим Extended: голос без инструментов + маршрутизатор `gemini-3.8-live` — 7 из 7 сценариев. Гонка подтверждения найдена и закрыта — [ADR-0006](../../docs/adr/0006-live-call-extended-router.md).
- [x] Архитектура: сервер-ретранслятор, Google видит только хост BB — [ADR-0005](../../docs/adr/0005-live-call-server-relay.md).
- [x] Протокол подтверждения `ConfirmationGate`: классы R/C/P/L, шлюз микрофона, одноразовые id — [спека §7.1](../../docs/specs/live-call.md).
- [x] Звонок = тред BB на скрытом провайдере — спайк пройден — [ADR-0007](../../docs/adr/0007-live-call-thread-provider.md), [research/spike-provider](research/spike-provider/).
- [x] Контракт для исполнителей: настройки, WS-протокол, setup Gemini, схемы инструментов, ConfirmationGate, тред звонка, протокол моста, системные инструкции, хранилище и CLI — [live-call-contract.md](../../docs/specs/live-call-contract.md).
- [x] Макеты UI/UX — [design/live-call-mockups.html](design/live-call-mockups.html).
- [x] Сэмплы 30 голосов — [research/probes/voice-samples.mjs](research/probes/voice-samples.mjs).

## Решения владельца (02.11.2026)

| Вопрос | Решение |
|---|---|
| Режим по умолчанию | ⚡ Обычный (`gemini-3.8-live`); 🧠 Extended — в один тап |
| Extended перестал отвечать | Спросить «перейти на Обычный?», модель без слова владельца не менять |
| Ключи | 2: основной и запасной, запасной — только при ошибке квоты |
| IP для Google | Только хост BB, браузер к Google не подключается |
| Что можно голосом | Чтение — сразу; сообщение, ответ агенту, стоп — после «да»; разрешение — после «разрешаю»; запуск и раздача — только после «запускай» |
| Где хранить звонки | Отдельный проект BB «Звонки», один звонок — один тред (подтверждено владельцем 02.11) |
| Голос и язык | Algenib, русский |
