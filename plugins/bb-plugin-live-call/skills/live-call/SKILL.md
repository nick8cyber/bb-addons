# Live Call — голосовой звонок с BB

## Как это устроено

- Кнопка 📞 (правый нижний угол или Настройки → Live Call) открывает живой голосовой диалог с координатором.
- Браузер даёт только микрофон и динамик; ключи, сессия и инструменты BB живут на сервере. К Google подключается сервер BB.
- Каждый звонок — отдельный тред в проекте «Звонки»: транскрипт выглядит как обычная переписка, его можно искать и цитировать.

## Что можно голосом

- Чтение (обзор BB, треды, память) — сразу.
- Сообщение в тред, ответ агенту, остановка треда — после «да».
- Разрешение агенту — только после «разрешаю».
- Запуск агента и раздача задач — только после «запускай». Одно «да» работу не запускает.
- Push, merge, деплой голосом недоступны — таких инструментов нет.

## Режимы

- Режим один: `gemini-3.8-live` с инструментами — Extended отключён (ADR-0006, пересмотр 2): модель Extended не вызывает инструменты и сама добавляет «системную ошибку».
- Звонок по треду — кнопка «Звонок по треду» (иконка телефона) в шапке треда (ADR-0009): голос сразу, без вопроса, коротко пересказывает ответ агента на последний запрос владельца; дальше — дочитка, сообщение или ответ агенту после «да», мозговой центр (сводка — справка, вопрос, задание с изменениями).
- Звонок по проекту — действие «Позвонить по проекту» в панели нового треда, команда палитры или иконка телефона у названия проекта (ADR-0011): ручки MCP-коннекторов проекта из реестра, подтверждённого кнопкой в настройках. Чтение — сразу, запись — после «да».
- Второй мозг есть и в звонке по треду, и в звонке по проекту: `acp-devin`, модель `swe-2-flash-medium`, reasoning `medium` (ADR-0017). В проектном звонке расчёты, вопросы за период и диагностика идут через `brain_ask`; мозг сам запрашивает разрешённые данные коннекторов. Изменения остаются у голоса с подтверждением; `brain_task` — только для звонка по треду.
- Переключение — кнопкой в оверлее или голосом. Пока ждёт подтверждение, переключение заблокировано.

## Где что лежит

- Транскрипты и журнал подтверждений: SQLite плагина, 90 дней.
- `bb call status | calls | transcript <id> | probe` — статус, список звонков, транскрипт, проба нативных вызовов Extended.
- `bb call connectors [--project <id>]` — поднять MCP-коннекторы проекта из реестра без звонка и показать ручки с итоговыми классами; занято, пока идёт звонок (контракт §14.8).
- Спека: `docs/specs/live-call.md`, контракт: `docs/specs/live-call-contract.md`; проектный мозг — `docs/specs/live-call-project-brain.md`, ADR-0017.

- Вопрос подтверждения короткий, полный текст на карточке. «Да» можно сказать, когда вопрос уже звучит; «да» до вопроса не засчитывается. Кнопка «Подтвердить» обрывает голос сразу.
