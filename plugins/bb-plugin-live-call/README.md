# `live-call` 📞 — живой голосовой звонок с координатором BB

> [!NOTE]
> Контракт — [docs/specs/live-call-contract.md](../../docs/specs/live-call-contract.md). Архитектура — [docs/specs/live-call.md](../../docs/specs/live-call.md). Что сделано и что дальше — [STATUS.md](STATUS.md).

Кнопка «Позвонить» открывает живой голосовой диалог с агентом-координатором поверх BB. Агент слышит, его можно перебить голосом. Он сам читает треды, пишет в них, запускает агентов (только по слову «запускай») и докладывает, когда агенты закончили.

## Ключевые решения

| Решение | Где |
|---|---|
| Браузер ↔ сервер BB ↔ Gemini Live. Google видит только IP хоста BB | [ADR-0005](../../docs/adr/0005-live-call-server-relay.md) |
|Режим|одна сессия `gemini-3.8-live` с инструментами; Extended отключён (ADR-0006, пересмотр 2)|
| Звонок = тред BB в проекте «Звонки» на своём провайдере «Live Call», транскрипт нативный | [ADR-0007](../../docs/adr/0007-live-call-thread-provider.md) |
| Запись и запуск — только после подтверждения, его проверяет сервер (`ConfirmationGate`) | спека §7.1 |
| Звонок по проекту — реестр коннекторов, подтверждение diff владельцем | [ADR-0011](../../docs/adr/0011-live-call-project-call.md) |

## Виды звонков

| Звонок | Вход | Что умеет |
|---|---|---|
| Координатору | кнопка «Позвонить» в сайдбаре, `Mod+Shift+L` | обзор BB, треды, задачи, память звонков |
| По треду | «Позвонить» в шапке треда | пересказ треда, дочитка, написать агенту после «да», мозговой центр (сводка, вопросы, задания) |
| По проекту | действие «Позвонить по проекту» в панели нового треда, команда палитры «Live Call: позвонить по проекту», иконка телефона в `bb-plugin-sidebar-collapse` | ручки MCP-коннекторов проекта из реестра, подтверждённого владельцем |

Все звонки — одна сессия `gemini-3.8-live` с инструментами.

## Входы в звонок по проекту (§15.1)

1. **Панель создания нового треда** (`experimental_newThreadPanelAction`):
   Действие «Позвонить по проекту». Если выбран проект со статусом `approved` в реестре, запускается звонок по проекту (`callEngine.start({ projectId })`). Если проект не настроен или изменения реестра ожидают подтверждения, выводится понятное уведомление.
2. **Команда палитры**:
   «Live Call: позвонить по проекту» — открывает выбор проекта из числа подтверждённых (`approved`) в реестре.
3. **Кнопка сайдбара и горячая клавиша `Mod+Shift+L`**:
   Остаются без изменений: обычный звонок координатору в один клик.
4. **Раздел настроек** (`SettingsSection`):
   Отображает список проектов реестра `projectCalls` со статусами (`approved`, `pending`, `invalid`). Для проектов в статусе `pending` показывается `diff` изменений и кнопки «Подтвердить» (`projectCallsApprove` с `hash`) и «Отклонить» (`projectCallsReject`).

## Межплагинные события window (§15.1)

Для интеграции с другими плагинами (например, `bb-plugin-sidebar-collapse`) используются события `window` (без жестких зависимостей между плагинами):

- `bb-live-call:projects` `{ projects: Array<{ projectId: string }> }` — публикуется плагином `live-call`:
  - при первичной загрузке плагина;
  - после подтверждения изменений реестра в настройках;
  - периодически каждые 60 секунд;
  - в ответ на событие-запрос `bb-live-call:projects-request`.
- `bb-live-call:projects-request` — отправляется другим плагином (например, `sidebar-collapse` при монтировании), чтобы `live-call` повторно опубликовал актуальный список подтверждённых проектов.
- `bb-live-call:start-project` `{ projectId: string }` — отправляется другим плагином (например, по клику на иконку телефона возле проекта в сайдбаре), чтобы `live-call` начал звонок по указанному проекту (`callEngine.start({ projectId })`).

## Структура плагина

```text
plugins/bb-plugin-live-call/
├── app.tsx                      # точка входа фронтенда (слоты BB, команды, события)
├── server.ts                    # бэкенд плагина (реестр, WS, MCP-клиенты, Gemini Live)
├── src/
│   ├── contract.ts              # типы протокола кадра и константы
│   └── ui/
│       ├── engine.ts            # движок звонка (WS, аудио захват/воспроизведение, токен)
│       ├── rpc.ts               # RPC клиент фронтенда
│       ├── project-events.ts    # публикация и слушатели событий window (§15.1)
│       ├── CallOverlay.tsx      # React-оверлей звонка (док, пилюля, мобильный вид, селектор проектов)
│       ├── SettingsSection.tsx  # настройки плагина и подтверждение реестра проектов
│       └── icons.tsx            # SVG-иконки
```
