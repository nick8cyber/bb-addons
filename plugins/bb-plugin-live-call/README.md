# `live-call` 📞 — живой голосовой звонок с координатором BB

> [!NOTE]
> Статус: **проектирование**. Кода плагина ещё нет. Здесь лежат спека, макеты и результаты проб. Контракт — [docs/specs/live-call.md](../../docs/specs/live-call.md). Что сделано и что дальше — [STATUS.md](STATUS.md).

Кнопка «Позвонить» открывает живой голосовой диалог с агентом-координатором поверх BB. Агент слышит, его можно перебить голосом. Он сам читает треды, пишет в них, запускает агентов (только по слову «запускай») и докладывает, когда агенты закончили.

## Ключевые решения

| Решение | Где |
|---|---|
| Браузер ↔ сервер BB ↔ Gemini Live. Google видит только IP хоста BB | [ADR-0005](../../docs/adr/0005-live-call-server-relay.md) |
|Режим|одна сессия `gemini-3.8-live` с инструментами; Extended отключён (ADR-0006, пересмотр 2)|
| Звонок = тред BB в проекте «Звонки» на своём провайдере «Live Call», транскрипт нативный | [ADR-0007](../../docs/adr/0007-live-call-thread-provider.md) |
| Запись и запуск — только после подтверждения, его проверяет сервер (`ConfirmationGate`) | спека §7.1 |

## Виды звонков (04.11)

| Звонок | Вход | Что умеет |
|---|---|---|
| Координатору | кнопка «Позвонить» в сайдбаре, `Mod+Shift+L` | обзор BB, треды, задачи, память звонков |
| По треду | «Позвонить» в шапке треда | пересказ треда, дочитка, написать агенту после «да», мозговой центр (сводка, вопросы, задания) |
| По проекту | «Позвонить по проекту» в панели нового треда (в работе) | ручки MCP-коннекторов проекта из реестра, подтверждённого владельцем |

Все звонки — одна сессия `gemini-3.8-live` с инструментами. Подробно — `docs/specs/live-call.md`, контракт — `docs/specs/live-call-contract.md`.
