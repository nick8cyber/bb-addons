# bb-plugin-usage-pro

Продвинутый плагин отображения квот и лимитов провайдеров искусственного интеллекта для bb (Blackbox).

Заменяет стандартный плагин `provider-usage` и предоставляет полную поддержку мульти-аккаунтов, быстрого переключения табов и детальной информации о времени сброса лимитов.

## Возможности

- **Мульти-аккаунты OpenAI Codex**:
  - Персональный аккаунт (`Plus`).
  - Командный аккаунт (`Team`), получаемый через `pi auth login --provider openai-codex` и авторизационный токен ChatGPT backend API.
- **Мульти-аккаунты Google Antigravity (Gemini & Claude)**:
  - Автоматическое обнаружение всех аккаунтов в bridge-хранилище (`.bb/plugins/provider-agy/bridge-data/accounts`).
  - Раздельный учет 5-часовых и недельных квот для нативных моделей Gemini и 3P-моделей (Claude/GPT).
  - Индивидуальное проксирование аккаунтов (HTTP/HTTPS прокси из файла `proxy`).
  - Определение статуса кулдауна (`cooldownUntilMs`) при исчерпании лимитов.
- **Claude Code**:
  - Отображение лимитов сессии и недельных квот с форматированием плана (`Team (5x)`).
- **Исключение лишнего**:
  - Полное удаление неиспользуемых артефактов Cursor.
- **Мгновенный отклик UI (0 мс)**:
  - Переключение табов срабатывает в момент нажатия (`onPointerDown`), не дожидаясь отпускания мыши (`mouseup`).
  - Защита от случайного запуска HTML5 Drag-and-Drop иконок (`pointer-events-none select-none`).
  - Устранен горизонтальный сдвиг `scrollLeft` (`overflow-visible`).
- **Стабильная геометрия окна (320px / 20rem)**:
  - Высота модального окна зафиксирована — окно не сжимается, не уползает и не дергается при переключении между провайдерами с разным количеством аккаунтов.
  - Список аккаунтов плавно скроллится внутри выделенного контейнера с изоляцией скролла.
- **Локализованные даты сброса и обратный отсчет**:
  - Наглядное отображение: `Сброс: Сегодня, 04:28` · `через 4ч 15м`, `Сброс: 26 сент., 22:11` · `через 6д 22ч`.
  - Цветовая индикация заполнения прогресс-бара (<80% синий, 80-94% желтый, >=95% красный).
- **Селективное кэширование (Stale-While-Revalidate)**:
  - При переключении табов загружаются только данные выбранного провайдера.
  - Кэш отдается за ~70–150 мс, а фоновое обновление не блокирует интерфейс.

## Автоповтор при workspace-limit отказе Codex

При структурированной ошибке `workspace_member_credits_depleted` плагин ставит повтор того же запроса в штатную очередь BB: через 15, 30, 60 и 120 минут после соответствующей неудачной попытки, с разбросом до 30 секунд. Максимум четыре автоматических повтора в одной цепочке. Текст ошибки не доказывает денежное состояние подписки; подпись в очереди — «Временный отказ Codex — автоматический повтор». Время восстановления провайдер не сообщает.

Повтор виден и отменяется в очереди треда BB; очередь переживает перезапуск сервера. Обычные одиночные сообщения, отложенные строго позже времени повтора, ему не мешают: их время, порядок и содержание сохраняются. Немедленный или более ранний ввод, группировки, другой retry и ожидания действий блокируют дополнительный повтор. Причина пропуска записывается в диагностике и журнале. Старые ошибки при включении плагина не переигрываются. Активные, остановленные, архивные и удалённые треды, сменившие провайдера треды не затрагиваются. Маршруты Account Pooler оставлены штатному обработчику. Аккаунты, модели и маршрутизация не меняются.

Диагностика: read-only RPC `usage-pro / creditRetry.status` с входом `{"threadId":"<id>"}` возвращает политику и последнее решение. `bb provider-retry explain` объясняет только решение встроенного обработчика: для кредитов он по-прежнему может показывать `not-resettable`, даже если наш плагин поставил повтор. Расписание проверяйте в очереди треда. Отключение `usage-pro` останавливает постановку новых повторов, но уже созданный повтор нужно отменить в очереди отдельно.

## Установка и использование

Плагин подключается как прямой аддон в bb:

```bash
# Проверка статуса плагина
bb plugin list

# Перезагрузка после изменений
bb plugin reload usage-pro
```

## Структура файлов

- `server.ts` — серверная точка входа, подключающая сохранённый сборщик квот и обработчик повторов.
- `credit-retry.ts` и `credit-retry.test.ts` — ограниченный автоповтор и тесты на официальном fake-host SDK.
- `dist/provider-usage-base.js` — сохранённый исходный backend-артефакт сборщика без изменения его логики; хранится в `dist`, чтобы сборщик CSS не сканировал его как frontend-исходник. Не удалять при очистке сгенерированных файлов.
- `dist/server.js` — итоговая серверная сборка: опрос квот, кэширование и автоповтор.
- `app.js` — стабильная frontend-точка входа; импортирует исходные стили и реэкспортирует клиентский bundle.
- `app.bundle.js` — клиентский bundle: модальное окно в футере сайдбара, кнопки табов, карточки квот и форматирование дат.
- `app.css` — исходные стили прогресс-баров, фиксация высоты окна (20rem) и настройки скроллбаров.
- `dist/app.js` и `dist/app.css` — генерируются `bb plugin build` и не являются исходниками.
- `package.json` — манифест плагина для системы плагинов bb.
