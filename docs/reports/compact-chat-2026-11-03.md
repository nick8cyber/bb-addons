# Компактный чат

Контракт: [завершение компактного интерфейса](../specs/compact-chat-complete.md), [предыдущий план](../specs/chat-chrome-047.md).

| Часть | Результат |
| --- | --- |
| Git-сводка и merge-base | Кнопка в верхней панели, штатные файлы и выбор базы в раскрытии |
| Фоновая команда | Верхняя кнопка Terminal, описания и длительность в раскрытии, длинные строки переносятся |
| Очередь | Первая свёртка штатной кнопкой; повторное ручное раскрытие сохраняется |
| Редактор и ошибки очереди | Не скрываются; новая ошибка раскрывается один раз |
| Мобильные действия | Область нажатия 44px, без горизонтального переполнения |
| Установка | Основная папка `plugins/bb-plugin-sidebar-collapse`, прежние настройки сохранены |

## Проверки

- [x] Чистый `npm ci`, SDK 0.6.104, TypeScript.
- [x] 126 frontend/pure + 6 server tests: 132 успешно; после уточнения наблюдения disabled/aria-controls — 20 targeted tests успешно.
- [x] Реальный BB shell в Chromium: 1440×900, 390×844, 360×520; светлая и тёмная темы.
- [x] Закрытые Git/фоновые карточки: 0px над вводом. Очередь: 32px desktop, 44px mobile.
- [x] Раскрытие/закрытие, Escape, границы viewport, native merge-base, мобильные действия и ручное раскрытие очереди. В изолированных DOM fixtures не было запусков команд, отправок сообщений или сетевых mutations; JavaScript errors: 0.
- [x] Настройки sidebar-collapse до/после установки идентичны; `bb--git.showGitChanges=true` возвращён для переноса сводки вместо отключения функции.

> [!NOTE]
> Advisor не выполнил автоматическое ревью: его служебный тред ожидает пользовательского ответа (HTTP 409). Автоматического одобрения нет. Код проверен координатором; результаты выше получены тестами и браузером.

Совместимость React header controls и native thread actions BB0.48 изолирована в `lib/host-compat.ts`: runtime ещё поддерживает эти публичные callbacks, хотя SDK исключил их старые декларации. Приватные импорты SDK не используются.

Rollback: установка прежнего source `worktrees/bb-addons-chat-chrome/plugins/bb-plugin-sidebar-collapse` через штатный BB CLI. Данные/настройки не удалять.
