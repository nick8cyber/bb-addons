# ADR-0042: Четыре уровня сложности, уровни ролей и правила цепочек моделей

## Контекст

До 23.11 у стенда было три исполнительских уровня (`complex`, `medium`, `simple`). Подпись `complex` включала «архитектуру», и координаторы отдавали проектирование исполнителям кода. Уровней `spec`, `architect` и `research` в политике не было, хотя граф задач (§27–§32) их использует. Одна и та же модель стояла у одного провайдера: при его сбое цепочка уходила на модель хуже, хотя та же модель отвечала у другого провайдера. Правило выбора уровня «сомневаешься — бери выше» без оговорок толкало задачи в самый дорогой уровень.

## Решение

1. **Исполнительские уровни кода:** редкий `complex` (дорогие модели с малыми лимитами) и постоянные `high`, `medium`, `simple` (почти безлимитные). Большинство задач — в постоянные уровни. Граф допускает `high` (§32.6).
2. **Уровни ролей:** `architect` — проработка архитектуры и итоговый аудит решения по вызову координатора, только самые сильные модели. Основная архитектура остаётся за тредом с ролью `architect`. Уровень спек — писатель спек по готовой архитектуре, **только сильные модели**. `research` — исследование по первичным источникам.
3. **Цепочки:** одна модель у нескольких провайдеров — маршруты подряд, бесплатные первыми, платные последними в группе модели. Каждый маршрут перед записью проверяется живым запросом. Порядок моделей — по первичным бенчмаркам кодинга (исследование PLUG-399), опыт владельца может его поправить.
4. **Выбор уровня координатором:** описание уровня главнее общего правила. Уровень, помеченный как редкий, — только при совпадении задачи с описанием. «Сомневаешься — бери выше» действует между постоянными уровнями.
5. **Источник правды по моделям — политика плагина.** Инструкции стенда (AGENTS.md) модели и порядок резерва не дублируют.

## Последствия

- Дорогие лимиты (Codex, Claude) тратятся на редкие крупные задачи, ревью и спеки, а не на рутину.
- Сбой одного бесплатного провайдера не роняет качество: та же модель берётся у следующего.
- Конкретные модели стенда описаны в KB (`infra/orchestrator-policy.md`), а не в спеке: плагин не содержит готовых наборов моделей (§2).

## Отклонённые варианты

- **Оставить три уровня.** Разница между Gemini Flash и бесплатными Flash-моделями слишком велика для одного `medium`.
- **Отдавать спеки быстрым моделям ради скорости.** Спека — контракт для всех исполнителей. Ошибка в ней дороже времени сильной модели.
