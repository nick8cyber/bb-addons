# Usage Pro — единый учёт квот и ошибки по источнику

## Решение

Учёт идёт по провайдерскому accountKey и host scope, а не по имени маршрута или email. Native Codex и Pi могут использовать одну подписку; разные способы подключения не создают вторую квоту. Два разных/неизвестных quota identities сохраняются раздельно. Тариф берётся из данных провайдера.

Валидный measurement error относится к account card. Общая ошибка host/RPC означает общий сбой сбора или неизвестный inventory, а не неисправность любого отдельного подключения. Старые данные при transport failure сопровождаются локальным предупреждением и не считаются новым успешным измерением.

## Сохранение реализации

Основой служит фактически установленный usage-pro из cccb12c: packaged collector и существующий bounded credit retry. Его четыре commit сведены только в изолированную candidate-ветку. Функциональность retry, авторизации, модели и routing не меняются. Миграция source path после проверки — без удаления plugin id/state.
