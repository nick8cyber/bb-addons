# ADR-0009. Звонок по треду

## Контекст

Агенты пишут в треды длинные ответы, и владелец не успевает их вычитывать. Он хочет обсуждать тред голосом на ходу: спросить «на чём он остановился», «что предлагает», и по команде написать агенту ответ.

Кнопка «Позвонить» в шапке треда уже есть (`app.tsx`, `experimental_threadAction`), но открывает обычный звонок координатору и тред не учитывает.

## Решение

1. **Звонок по треду** — отдельный вид звонка. Начинается кнопкой «Позвонить» в шапке треда и привязан к этому треду до конца звонка.
2. **Режимы как в обычном звонке:** по умолчанию Extended (ADR-0006, пересмотр 03.11), переключатель на «Быстрый» в окне звонка.
3. **Контекст:** первые 10 и последние 20 сообщений треда целиком, без обрезки. Сообщение — это запрос владельца или текстовый ответ агента. Вывод инструментов (команды, логи, конфиги) не берётся: он занимает основной объём, в нём пути и порты, а для пересказа он не нужен.
4. **Где лежит контекст:** в системной инструкции голосовой сессии, а не в разговоре, чтобы сжатие контекста (`COMPRESSION`, 20k → 10k) его не выкинуло. В Extended помощник (ROUTER) получает только название треда и инструменты, без текста треда.
5. **Инструменты только для этого треда:**
   - дочитать сообщения (класс R, без подтверждения);
   - написать в тред (класс C, после «да»);
   - ответить на вопрос агента (C, «да») или разрешить действие (P, «разрешаю»).

   Остальные инструменты общего звонка (другие треды, запуск агентов, задачи, память BB) в звонке по треду отключены.
6. **Ввод текстом** (кадр `text`, первоначально из коммита `c0654b6`) входит в эту фичу для тестов без синтеза речи. Подтверждения текстом не работают: подтверждают голосом или кнопкой (кадр `confirm`).

## Замер (03.11)

Первые 10 + последние 20 сообщений (только владелец и тексты агента) на 5 реальных тредах: 7–49 тыс. символов, ≈2,5–16 тыс. токенов (оценка «символы / 3»). Самое длинное сообщение — 7 тыс. символов.

> [!WARNING]
> С голосовой инструкцией (~3 тыс. токенов) большой тред подходит к порогу сжатия 20 тыс. Что сжатие Live API сохраняет системную инструкцию, **не проверено**. Это первый шаг реализации (контракт §12.6): если не сохраняет — для звонка по треду поднять порог сжатия.

## Последствия

- Владелец обсуждает тред голосом и не читает простыни.
- Писать в тред — только после «да»: голос повторяет текст одной фразой перед отправкой.
- «Системная ошибка» Extended (STATUS, PLUG-102) касается и этого звонка, пока причина не найдена.

## Отвергнуто

- **Обрезать длинные сообщения** — владелец отверг: пересказывать нужно как раз длинные.
- **Класть тред в обе сессии Extended** — удваивает объём, помощнику текст не нужен.
- **Весь тред целиком** — у больших тредов сотни сообщений; середину агент дочитывает по запросу.
