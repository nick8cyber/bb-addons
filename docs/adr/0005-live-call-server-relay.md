# Live Call — сервер-ретранслятор, Google видит только хост BB

## Решение

Звонок идёт двумя WebSocket-плечами: браузер (или телефон) ↔ плагин на сервере BB через BB Connect, и плагин ↔ Gemini Live напрямую. Ключи AI Studio, сессия и инструменты BB живут на сервере. Браузер — только микрофон и динамик.

**Google видит только IP хоста BB** (требование владельца). Браузер к Google не подключается. Плагин не пересылает в Google ничего от клиента: ни IP, ни `X-Forwarded-For`, ни `User-Agent`, ни cookies. Фронтенд плагина не загружает ничего с доменов Google.

## Почему

- Ключи не покидают сервер.
- Инструменты исполняются там же, где `bb.sdk`.
- Будущие звонки из Telegram, по SIP или через своё приложение — это другой транспорт к тому же ядру.
- CLIProxy Live WebSocket не проксирует (HTTP 404 на `BidiGenerateContent`), поэтому соединение с Google идёт напрямую, а не через шлюз.

## Отвергнуто

Браузер ↔ Google по ephemeral token. Задержка ниже, но Google видит IP клиента, сессия умирает вместе с вкладкой, инструменты приходится гонять через браузер. Запрещено требованием выше.
