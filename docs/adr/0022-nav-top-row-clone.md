# Клонирование навигации в top-row вместо репарентинга

Контракт — [спека nav-icon-row](../specs/nav-icon-row.md).

## Контекст

Владелец потребовал все действия навигации в одну верхнюю строку рядом с нативными кнопками Toggle/Назад/Вперёд. Блок навигации (`sidebar-navigation-region`) принадлежит встроенному плагину `navigation` — React-дерево чужое, источника нет. Попытка физически перенести узлы в `[data-testid="app-sidebar-top-reserve-row"]` была заблокирована хостом («tried to move … out of React's tree»).

## Решения

1. **Клон вместо переноса.** `lib/nav-top-row.ts` строит кнопки-клоны в `.bb-nav-top-icons` внутри top-reserve-row и пробрасывает `pointerdown → pointerup → click` на настоящие кнопки. Настоящие элементы остаются в своём React-дереве — обработчики, контекст и порталы Radix работают штатно. Один `click()` Radix-popover не открывает: ему нужна последовательность pointer-событий.
2. **Клонируется `svg`, не обёртка.** Копирование `[data-icon-root]` целиком тянуло лишние классы и ломало сетку размеров — визуальное «наложение» первых иконок.
3. **Источник прячется на месте, а не за экраном.** `position:absolute; visibility:hidden; pointer-events:none` сохраняет координаты якоря popover «Ещё»; ранний вариант `top:-200vh` уносил якорь, и меню открывалось вне вьюпорта — выглядело как «кнопка не работает».
4. **Отступ от нативного Toggle.** Фиксированная кнопка `Toggle sidebar (⌘\)` нарисована поверх начала ряда — хосту сдвигаем `.bb-nav-top-icons` на правый край её `getBoundingClientRect()`. Геометрия проверена живой диагностикой (x=42/72/102/132, пересечений нет).
5. **`setInterval` + подпись вместо `MutationObserver`.** Наблюдатель за документом реагировал на собственные вставки клонов — бесконечная пересборка заморозила хост. Интервал 1.5с перестраивает только когда подпись источников (aria-label + icon) изменилась.
6. **Бейдж-точку клон не рисует.** Владелец уже отключил агрегат открытых задач в теме (`6042799`); первые версии клона возвращали её — регрессия убрана в `74200ba`.
7. **Диагностика за флагом `navDiag`.** Playwright запрещён; живая проверка — канал content script → overlay → RPC → `/tmp` плюс командный файл (самотест «Ещё», пробники зон). По умолчанию выключен: нет опросов, RPC и записей в `/tmp`.

## Последствия

- Клон — не React-узел: стили задаются нашим CSS (`.bb-nav-top-icons > button svg`), темы BB на него ложатся частично; при смене разметки top-row всё fail-open отключается.
- Между источником и клоном возможен лаг до 1.5с на ресинхронизацию (редкая смена набора пунктов).
- `navDiag` — единственный санкционированный способ живой верификации; отключать его после сеанса отладки обязательно.
- Переименование плагина `sidebar-collapse → compact-ui` (`7f8041b`) меняет провайдер списка: `sidebar.threadListProvider` должен быть `compact-ui/collapsed`; при миграции со старого id список падает с «No thread list plugin» — правится прямой записью в `ui_preferences` или повторным выбором в Settings → Appearance.
