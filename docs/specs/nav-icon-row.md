# Контракт

Владелец поручил уменьшить вертикальное меню навигации сайдбара («Новый тред», «Поиск по тредам», «Задачи Pro», «Ещё»): четыре текстовых пункта занимали ~143px и требовали редизайна в одну строку иконок. Блок принадлежит встроенному плагину `navigation` (нативная обёртка `sidebar-navigation-region`, placement `list`) — исходник недоступен, рестайл делается host-стилями в существующем compact-ui (плагин space-оптимизаций). Новый плагин не создавать.

## Требования

1. **Одна горизонтальная строка иконок** внутри `[data-testid="sidebar-navigation-list"]`: destinations (`[data-sidebar-navigation-item]`) и кнопка «Ещё» выстраиваются flex-row, регион сжимается с ~143px до ~57px desktop (~69px mobile).
2. **Только иконки**: текстовые лейблы скрываются (`button > :not([data-icon-root])`), кнопки квадратные `var(--bb-sidebar-row-height)`. aria-label и title сохраняют подсказки и доступность.
3. **Chevron «Опции» каждого пункта скрываются** (`.bb-sidebar-hover-actions`): действия остаются доступны внутри самих панелей/меню.
4. **Badge-точка у «Ещё» не создаётся**: агрегат открытых задач отключён владельцем в теме (коммит `6042799`, `[data-sidebar-navigation-item] .rounded-full { display:none }`); клон точку не воспроизводит. Ранние итерации рисовали `.bb-nav-top-badge` — убрано в `74200ba` по слову владельца (точку уже отключали, «спокойный rail без точек»).
5. **Режим rail не затрагивается**: правила скоплены под `[data-testid="sidebar-navigation-list"]`, который существует только в list-раскладке; вертикальная rail-колонка не меняется.
6. **Иконка Tasks Pro**: `ListFilter` → `ListTodo` (app.tsx navPanel + package.json branding) — метафоры «список задач» вместо «фильтр».
7. Fail-open: если BB переименует разметку — правила молча перестают действовать, интерфейс штатный.

## Проверка и выпуск

- Тесты compact-ui 134/134 + typecheck + build.
- Chromium desktop 1440×1050: регион 57px, иконки MessageSquarePlus/Search/ListTodo/MoreHorizontal в одном ряду, badge на месте. Mobile 390×844: ряд 40px-кнопок, та же строка.
- Откат: удаление CSS-блока navigation из `SIDEBAR_CONTROLS_CSS`; иконка tasks-pro — возврат `ListFilter`.

## Подъём в верхний chrome-ряд (8e64f10 → финал)

Иконки дополнительно клонируются в `[data-testid="app-sidebar-top-reserve-row"]` — слева, стрелки «Назад/Вперёд» остаются справа (`lib/nav-top-row.ts`). Прямой репарентинг React-узлов невозможен: BB блокирует вынос из дерева — клон и проброс событий вместо этого.

Механика финальной реализации:

1. **Полный проброс событий** `pointerdown → pointerup → click` на настоящую кнопку-источник: один `click()` не открывает Radix-popover «Ещё».
2. **Клонируется сам `svg`** (`[data-icon-root] svg`), не обёртка — иначе CSS-размеры не ложатся и иконки визуально «налезают».
3. **Родной регион прячется на месте** (`position:absolute; visibility:hidden; pointer-events:none`), а не выносом за экран: `-200vh` уносил якорь, и popover «Ещё» открывался вне вьюпорта. Источник остаётся живым для нативных обработчиков и порталов Radix.
4. **Сдвиг от нативного Toggle**: нативная fixed-кнопка `Toggle sidebar` перекрывает первый клон — `.bb-nav-top-icons` получает left-margin по `getBoundingClientRect()` тогла.
5. **Ресинхронизация** — `setInterval` 1.5с с подписью источников (aria-label+icon+badge); MutationObserver не используется (постмортем ниже).
6. **Канал самодиагностики `navDiag`** (настройка, выкл. по умолчанию): content script → overlay bridge → RPC → `/tmp/compact-ui-nav-top-row.json` + командный файл `/tmp/compact-ui-nav-cmd.txt` (самотест «Ещё», пробники точек/зон). Нужен для живой проверки DOM без Playwright. В выключенном состоянии — никаких опросов, RPC и записей.
7. **Fail-open**: без top-row или источников ничего не вставляется, меню штатное; регион не скрывается, пока клон не смонтирован (`data-bb-nav-icons-active`).

**Постмортем — MutationObserver:** первая версия наблюдателя пересобирала клоны от собственных вставок — бесконечный цикл заморозил хост. Урок: не наблюдать DOM, который сам мутируешь.

**Постмортем — badge:** клонированный бейдж `.rounded-full` изначально рендерился серым шаром (унаследованные позиционные классы); заменён своей 8px точкой `.bb-nav-top-badge`, а затем удалён полностью — точку задач владелец уже отключил в теме, дублировать её нельзя.
