# Live Call — где показывать кнопку звонка

## 1. Зачем
Футер сайдбара у клиента — ряд иконок (лимиты, звонок, телефон, «…»). Владелец уносит звонок в левую панель навигации, освобождая место под полосу лимитов машин (usage-pro-all-machines, `footerMachines`). Нужна настройка «где показывать кнопку звонка». У всех остальных установок ничего не меняется — значение по умолчанию соответствует текущему виду (футер).

## 2. Настройки — два независимых тумблера
Секция настроек плагина «Live Call», два boolean-контрола:

| Тумблер | По умолчанию | Где кнопка |
|---|---|---|
| «Кнопка звонка в нижнем сайдбаре» (`callButtonFooter`) | **вкл** | нижний футер сайдбара — ровно как сейчас |
| «Кнопка звонка в левой панели» (`callButtonNav`) | **выкл** | левая панель навигации (иконочная строка destinations) |

Комбинации: вкл+выкл — только футер (дефолт, ничего не меняется); выкл+вкл — только левая панель; вкл+вкл — оба места; выкл+выкл — нигде (звонок остаётся по `Mod+Shift+L` и командам палитры).

Механизм хранения — прямой localStorage с синхронными getter/setter и своим хуком (как `getHideClaude()/setHideClaude()/useHideClaude()` в usage-pro; `useSettings` синхронно при старте `definePluginApp` не вызвать). Ключи: `bb_live_call_button_footer`, `bb_live_call_button_nav` (значения `"0"|"1"`). Невалидное значение или ошибка доступа к localStorage → фолбэк к дефолту (footer вкл, nav выкл).

## 3. Поведение

### 3.1. Футер (`footer`)
Существующая регистрация `experimental_sidebarFooter.register({ kind:"action", id:"call" })` — без изменений (`callOrFocus`: нет звонка — позвонить, идёт — развернуть док).

### 3.2. Левая панель (`nav`)
Левая панель — нативный регион навигации (`[data-sidebar-navigation-item]`, туда же попадает «Задачи Pro»). Единственная поверхность SDK, дающая туда иконку плагина, — `app.slots.navPanel`:

- Регистрация `navPanel`: `id:"call"`, `title:"Live Call"`, `icon` — глиф телефона плагина, `path:"call"`.
- **Автозвонок только при клиентском переходе.** Компонент панели вызывает `callOrFocus()` при монтировании, но **только если app-бандл загружен давно** (отметка времени в `definePluginApp`; порог ~3 с). При свежей загрузке документа (F5 / восстановление вкладки на URL панели / перезагрузка из §3.4) автозвонка **нет** — иначе открытие микрофона и сессия Gemini происходили бы без жеста пользователя. StrictMode-двойной mount безвреден: `callOrFocus` идемпотентен при активном звонке (requestExpand).
- Тело панели — экран управления звонком (страница не тупик): статус «идёт звонок · mm:ss» / «звонка нет» и кнопки **«Позвонить»**, **«Развернуть»** (при активном свёрнутом звонке — разворачивает док, покрывает повторный клик по иконке без перемонтажа), **«Завершить»**. Оверлей звонка работает как обычно.

### 3.3. Оба включены / оба выключены
- Оба тумблера вкл — регистрируются и футерная кнопка, и navPanel.
- Оба выкл — не регистрируется ни одна; `Mod+Shift+L` (`call-toggle`), команда «позвонить по проекту» и остальные входы §15.1 п. 1–2 контракта — без изменений.

### 3.4. Применение
Регистрации слотов одноразовые (у footer-action нет unregister, navPanel декларативная): значение читается один раз при старте app-бандла, **смена настройки применяется после перезагрузки страницы**. Под контролом в секции настроек — строка-подсказка «Применяется после перезагрузки страницы».

- Документы: этот файл; `docs/specs/live-call-contract.md` §15.1 п. 3 — пометка, что место кнопки сайдбара управляется тумблерами `callButtonFooter`/`callButtonNav`; раздел в `plugins/bb-plugin-live-call/README.md`.

## 5. Не делаем
- Переключение без перезагрузки — нет (API снятия регистрации отсутствует; неблокирующее ограничение, зафиксировано в подсказке §3.4).
- Иконка-«кнопка» без панели в левом rail — нет (navPanel всегда открывает свою страницу; автозвонок §3.2 при клиентском переходе делает поведение эквивалентным кнопке).
- Проверка иконки: `PHONE_ICON` у плагина — кастомный id `live-call/phone`, а `nav-icon-row` (спека, п. 6) опирается на `[data-icon-root] svg` и Lucide-иконки. Исполнитель проверяет, принимает ли `navPanel` кастомный id глифа (иначе Lucide `Phone`) и попадает ли `<svg>` внутрь `[data-icon-root]`.
- Изменение поведения звонка, оверлея, шортката — нет.

## 6. Проверка
1. `npx vitest run`, `npx tsc --noEmit`, `bb plugin build .` в `plugins/bb-plugin-live-call` — зелёные.
2. Снимки (ранбук KB `infra/ui-screenshots-runbook.md`): дефолт (футер вкл, панель выкл), иконка в левой панели, оба места, нигде — после перезагрузки; страница панели после клика.
3. Координатор: на BB клиента — футер выкл + панель вкл, проверить клик по иконке и освобождение места в футере.
