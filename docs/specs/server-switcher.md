# server-switcher — переключение между серверами bb из сайдбара

Статус: принято и реализовано. Плагин `plugins/bb-plugin-server-switcher`.

## 1. Назначение

Плагин добавляет в подвал боковой панели интерфейса BB компактный элемент управления текущим подключением:

- **Отображение текущего сервера**: мгновенная индикация того, на каком сервере и хосте находится пользователь.
- **Быстрое переключение**: раскрывающийся список доступных серверов учетной записи с переходом в один клик.
- **Поддержка трех платформ**: веб-браузер, десктопное приложение BB и мобильное приложение.
- **Индикация доступности**: отображение статуса онлайн/офлайн каждого сервера в реальном времени; недоступные серверы блокируются для клика.
- **Обратная совместимость с ring-store**: сохранение серверного хранилища и CLI-команд управления кольцами серверов при монохромном интерфейсе панели.

## 2. Архитектура и режимы окружения

Плагин автоматически определяет платформу выполнения с помощью функции `detectSwitcherMode` (`servers.ts`):

### 2.1. Десктопный клиент (`kind: "desktop"`)
- Обнаруживает объект хоста `window.bbDesktop`.
- Использует методы нативного API десктопа: `getServerChoices()`, подписку `onServerChoicesChange()` и команду выбора `selectServer(id)`.
- Переключение серверов делегируется нативному контейнеру приложения.

### 2.2. Мобильное приложение (`kind: "mobile-shell"`)
- Обнаруживает мост `window.ReactNativeWebView`.
- Список серверов переводится в режим только для чтения (`interactive = false`).
- Пользователю выводится подсказка переключать сервер через системное меню мобильного приложения.

### 2.3. Веб-интерфейс в браузере (`kind: "web"`)
- Стандартный режим работы в браузере.
- Клик по онлайн-серверу выполняет прямой переход по URL: `window.location.assign(row.url)`.

## 3. Источники данных и зависимости

Плагин опирается исключительно на официальные системные расширения BB:
- **Авторизация**: опрос RPC плагина `bb-account` (`bb-account.v1.status`). Если статус `signed-out`, панель отображает приглашение авторизоваться.
- **Список серверов аккаунта**: вызов RPC встроенного плагина `connect` (`listAccountServers`). Возвращает список серверов (`handle`, `name`, `live`, `url`) и идентификатор текущего сервера (`selfHandle`).
- **Контент-скрипт аватара**: скрипт `account-avatar` (`avatar-ui.tsx`) отслеживает статус профиля и обновляет аватар в реальном времени.

## 4. Хранилище колец (Ring Store) и совместимость

Плагин включает историческую подсистему персонализации серверов цветными кольцами (`rings.ts`, `ring-store.ts`):
- **Модель данных**: карта `Rings` вида `{ [serverHandle]: RingSetting }`. Настройка может быть градиентом из двух цветов, сплошным цветом или `"none"`.
- **Хранилище**:
  - Ключ `rings` в `bb.storage.kv` — сериализованные настройки.
  - Ключ `ringsRevision` в `bb.storage.kv` — монотонно растущий целочисленный счетчик версий для исключения конфликтов записи.
- **Канал реального времени**: публикации в `bb.realtime` по каналу `rings` (`RINGS_CHANNEL`) для мгновенной синхронизации открытых вкладок.
- **Монохромный дизайн UI**: в актуальной версии 0.1.3 интерфейс панели оформлен в строгом монохромном стиле (иконка `ComputerCloud`, отсутствие цветных колец и пикера цветов), однако слой хранения, RPC и CLI сохранены для обратной совместимости.

## 5. UI-интеграция и DOM-контракты

### 5.1. Регистрация в подвале сайдбара
Регистрируется через `app.experimental_sidebarFooter.register`:
- `kind: "disclosure"`
- `id: "servers"`
- `label: "Servers"`
- `icon: "ComputerCloud"`
- `component: ServerSwitcherPanel`

### 5.2. Состав и поведение панели
- Панель по умолчанию закрыта и открывается только по явному клику пользователя.
- **Карточка текущего сервера (`CurrentServerCard`)**:
  - Отображает иконку `ComputerCloud` с индикатором статуса `live` (зеленый кружок для доступных, серый для недоступных).
  - Имя (`row.name`) и описание (`row.detail`) текущего сервера в блоке с атрибутом `aria-current="true"`.
- **Секция переключения («Switch to»)**:
  - Список остальных серверов аккаунта.
  - Недоступные (офлайн) серверы отображаются с пониженной прозрачностью (`opacity-50`) и атрибутом `disabled`.
  - Клик по доступному серверу мгновенно закрывает панель (`dismiss()`) и инициирует смену сервера.

## 6. Серверные методы (RPC) и CLI

### 6.1. RPC-контракт (`ringsContract`)
- `listRings`: возвращает снимок `{ revision, rings }`.
- `setRing({ key, ring })`: атомарно обновляет кольцо для сервера `key`, увеличивает `revision` и публикует событие в канал реального времени.

### 6.2. Консольный интерфейс `bb server-switcher`
- `bb server-switcher ring list`: вывод списка настроенных колец серверов.
- `bb server-switcher ring set <server> <color> [<color>]`: установка одноцветного или двухцветного градиентного кольца.
- `bb server-switcher ring clear <server>`: отключение кольца для сервера (`"none"`).
- `bb server-switcher ring reset <server>`: сброс кольца к поведению по умолчанию (`null`).

## 7. Тесты, сборка и верификация

- **Сборка**: `bb plugin build .` → `dist/app.js` и `dist/server.js`.
- **Типизация**: `npm run typecheck` (`tsc --noEmit`).
- **Тесты**: Vitest (`vitest run`):
  - `servers.test.ts`: парсинг статусов аккаунта, валидация схемы серверов, извлечение хостов, обработка сетевых ошибок.
  - `rings.test.ts`: сериализация цветов, расчет градиентов, парсинг аргументов CLI.
  - `ring-store.test.ts`: управление очередью мутаций стора, дебаунс отправки, обработка конфликтов ревизий.
- **Комплексная проверка**: `npm run verify` (`typecheck && test && build`).

## 8. Известные ограничения и граничные случаи

- **Зависимость от Connect**: если плагин `connect` выключен или учетная запись BB не привязана, переключение между удаленными серверами невозможно (панель сообщает об отсутствии связи с аккаунтом).
- **Мобильный шелл**: в нативном мобильном приложении переключение серверов через веб-инъекцию невозможно из-за изоляции контейнера React Native, список выполняет исключительно информационную функцию.
