# Privacy Blur — скрытие чувствительных данных в интерфейсе bb

## 1. Запрос владельца

По клику скрывать (размывать) в интерфейсе bb все чувствительные данные: почты, id, пути, имена, названия проектов, названия инстансов и прочее. Нужно для скриншотов и показа экрана. 05.11: размытие было слишком слабым, буквы угадывались; сила маски увеличена, охват не расширялся.

## 2. Поведение

Плагин `privacy-blur`, пакет `bb-plugin-privacy-blur`, живёт в `plugins/bb-plugin-privacy-blur`.

| Действие | Результат |
|---|---|
| Кнопка `EyeOff` в подвале сайдбара | Включить/выключить режим |
| `Alt+Shift+P` | То же с клавиатуры |
| Плашка «Данные скрыты» справа внизу | Видна, пока режим включён; клик — выключить |

Состояние хранится в `localStorage` браузера (`bb-privacy-blur:enabled`) и синхронизируется между вкладками через событие `storage`. Удалённый клиент и локальное окно переключаются независимо.

### 2.1. Что скрывается по умолчанию

- **Шаблоны:** почты; URL; абсолютные, `~/` и Windows-пути; id bb (`thr_`, `proj_`, `env_`, `msg_`, `mem_`, `host_`, `src_`, `mach_`); прочие `prefix_id` только с цифрой; UUID; hex от 12 символов; ключи `sk-`, `ghp_`, `xox*-`, `AKIA`, `AIza`, JWT; IPv4/IPv6; домены из списка TLD; телефоны `+…`; `@логины`.
- **Слова с сервера** (`autoTerms`): названия проектов (кроме личного), имена хостов, hostname и пользователь ОС, `git config --global user.name/email`, хост публичного адреса bb.
- **Слова фронтенда:** хост страницы и его первая метка (`sursun` из `sursun.getbb.app`), имена и хосты серверов из `experimental_useServers`, проекты и хосты сайдбара.
- **Свои слова** (`customTerms`): через запятую или с новой строки.
- **Элементы целиком** (`filter: blur(7px)`): поля ввода без фокуса (`blurInputs`), терминал `.xterm` (`blurTerminal`), аватары (`blurAvatars`), `extraSelectors`.

Слова короче 3 символов не скрываются: «BB» остаётся видимым. Слова ищутся без учёта регистра, по границам слова Unicode.

### 2.2. Опции, выключенные по умолчанию

- `blurThreadTitles` — заголовки тредов везде: сайдбар, шапка, списки. Заголовки из `experimental_useSidebarThreads` становятся словами, плюс CSS по `[data-sidebar-thread-id] > span` и `.bb-thread-title`.
- `detectNames` — имена людей эвристикой «два слова подряд с заглавной» (`Иван Петров`, `John Smith`). Возможны ложные срабатывания на подписях интерфейса.

### 2.3. Вид маски

Текстовое совпадение закрывается непрозрачной серой плашкой `rgb(140,140,140)` с размытыми краями (`text-shadow`), текст прозрачный. Форма букв не угадывается даже при увеличении 2×.

## 3. Устройство и ограничения

Устройство и обоснование — [ADR-0013](../adr/0013-privacy-blur-highlight-mask.md).

- Content script держит движок; React-оверлей получает настройки по RPC `privacy_options` и слова из хуков SDK.
- Настройки с сервера кэшируются в `localStorage` (`bb-privacy-blur:options`) и проверяются по типам при чтении.
- Новый текст сканируется синхронно в колбэке `MutationObserver`, то есть до отрисовки: открытого кадра нет.
- Не скрываются: адресная строка браузера, всплывающие `title`, содержимое `<canvas>` (кроме терминала целиком). Текст, разбитый на несколько DOM-узлов, ловится по частям.
- Нужен CSS Custom Highlight API (Chrome 105+, Safari 17.2+, Firefox 140+). Без него размывается весь родительский элемент совпадения.
