# Компактные панели чата

## Контракт

1. В строке треда Sidebar Collapse остаются «Скопировать ссылку» и «⋯». Архивация доступна только внутри меню и контекстного меню. Пагинация, клавиатура и копирование сохраняются.
2. Сводка `Untracked · N files` переносится из области ввода в штатный `experimental_threadHeaderAction`. На узком экране — иконка и число, полное описание доступно через aria-label/title. Кнопка управляет родным раскрытием changed files; список визуально открывается под верхним баром, не занимает высоту над полем ввода. Действия файлов остаются штатными.
3. Адаптация DOM через content-script/эффект без перемещения React-узлов. Поиск native toggle/body ограничен ближайшим data-split-pane-id: каждый header управляет только своим pane. Подписки без polling, освобождаются при смене треда/unmount. Изменение числа/состояния обновляет header. Нет родной панели/неизвестный DOM — нет подмены, родной интерфейс остаётся доступным. При удалении эффекта все собственные атрибуты/стили удаляются. Родительская панель с другими context segments не скрывается.
4. Список файлов открывается внутри границ pane/viewport; Escape и внешний клик закрывают его. Escape возвращает фокус верхней кнопке. Блокировки native control сохраняются. Внешние меню/диалоги native file actions не закрываются преждевременно.
5. На мобильном до 767px родные действия queued-message видны постоянно без предварительного нажатия «⋯»: отправить/редактировать/удалить, только когда BB их рендерит. Сохраняются disabled, статусы отправки/ожидания, reorder, attachment и текст строки. Действия занимают место в flex-строке, не накрывают текст. Соседняя кнопка «⋯» скрывается только при наличии родного блока действий; inline editor и desktop без изменений. Никаких автоматических отправок, правок или удаления очереди.

## Реализация и приёмка

Один существующий плагин `plugins/bb-plugin-sidebar-collapse`, без BB core/нового плагина. `app.tsx`: архив только в меню, header slot. Отдельный модуль `lib/git-header.ts` с управлением native DOM и cleanup; `lib/sidebar-controls.ts`: узкие mobile CSS-селекторы. README отражает новое поведение. Старый контракт sidebar-controls-047 по постоянному архиву заменён этим запросом владельца.

- Unit: row copy/menu и archive только через menu fake host; header mount/label update/open/close/disabled/несколько pane/замена source/cleanup/отсутствие родного DOM; очередь CSS scoped, fallback «⋯» и disabled.
- `npm ci`, `npx vitest run --maxWorkers 1 --testTimeout 30000`, `npm run typecheck`, `bb plugin build .`, `git diff --check` от документного коммита.
- Chromium: desktop/mobile light/dark; верхняя сводка, исходная панель не занимает место, штатное открытие/закрытие списка, файловые действия без навигационной регрессии, resize/смена route; mobile queue actions видны и помещаются. Проверять очередь read-only, изменения/отправку перехватить в изолированной браузерной сессии либо fake DOM. Настоящие сообщения не отправлять/удалять и треды не архивировать.
