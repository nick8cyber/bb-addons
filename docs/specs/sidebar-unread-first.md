# Непрочитанные ветки сверху

## Контракт

В плагин sidebar-collapse добавляется настройка `unreadFirst` (boolean, по умолчанию `false`), отображаемая как «Непрочитанные сверху». Она сохраняется штатными настройками BB и применяется без перезагрузки страницы.

Внутри каждого проекта корневые ветки сортируются: закреплённые первыми; затем ветки, у которых непрочитан сам корень или любой неархивный потомок; затем прежний порядок по времени активности и id. Дочерние треды остаются под родителем в прежнем порядке создания. При выключенной настройке порядок полностью совпадает с прежним.

Лимит обычных корневых чатов, Show more/less, сворачивание проектов, видимость активной ветки и чатов, требующих внимания, сохраняются. Архивные потомки не поднимают ветку; циклические связи не должны приводить к зависанию. Прочитанность и состояние закрепления не изменяются.

## Проверка

Юнит-тесты порядка, выключенного режима, закреплений, непрочитанных потомков, лимита и архивных веток; frontend-тест применения настройки. Typecheck, полный набор тестов плагина и `bb plugin build`. После установки проверить сохранение `unreadFirst` и активность `sidebar-collapse/collapsed`.

## Границы

BB не обновляется; другие плагины и треды не меняются. Для включения опции пользователь меняет только `unreadFirst`.
